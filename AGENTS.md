# Repository layout

The only active application is app/. Before work read app/AGENTS.md, app/CONTINUE-HERE.ar.md, app/PROJECT-HISTORY.ar.md, app/HANDOFF.ar.md and app/README.md. These files preserve context across accounts without assuming the prior chat is available. Run all pnpm, TypeScript, PHP test/build commands with app/ as the working directory. archive/ is non-runtime historical reference: do not import, seed, deploy or merge its settings into the current app. Never include local credentials, signing keys, backups, real patient data, raw chat transcripts or screenshots in GitHub. Preserve the approved interface, SQL data, permissions and exact-cent financial contracts. After each work cycle update the current handoff and record material decisions, verification boundaries and remaining actions in the project history. Do not rewrite an already delivered runtime archive for a documentation-only change.

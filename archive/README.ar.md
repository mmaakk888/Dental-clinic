# أرشيف غير مخصص للتشغيل

النسخة المعتمدة الوحيدة على GitHub موجودة في `app/`. لا تخلط ملفات هذا الأرشيف معها ولا ترفع الأرشيف إلى الاستضافة.

- `legacy-metadata.json`: وصف قديم لبيئة إنشاء سابقة؛ لا تستعمله نسخة PHP/MySQL، لذلك أُخرج من مصدر التطبيق وحزمة النشر.
- [النسخة القديمة الكاملة قبل توحيد المستودع](https://github.com/mmaakk888/Dental-clinic/tree/9062beb3e3e4dcb1f6577ce296f7c3f647d7734a): محفوظة في تاريخ Git، بما فيها أدلتها وملفات تشغيلها القديمة. الرابط ثابت؛ لم تُحذف هذه النسخة نهائيًا ولم تُخلط بالمصدر الحالي أو تُنسخ إعداداتها إلى التطبيق.
- [نسخة PHP/MySQL v8 قبل تحسينات هذه الدورة](https://github.com/mmaakk888/Dental-clinic/tree/1978822a45c47a6a71f9f2a092a8b28397522cb3): نقطة رجوع مصدرية، وليست أمرًا بإرجاع قاعدة بيانات قديمة.

ملفات الاختبار الحالية والأدلة وأدوات البناء والاسترجاع مرتبطة بالمشروع وتبقى في `app/`؛ ليست مخلفات. بيانات المرضى ومفاتيح التوقيع وملفات الاتصال والنسخ الخاصة لا توضع في هذا الأرشيف أو GitHub مطلقًا. أدوات اللاب والاختبارات المحلية في `.clinic-local/` مستبعدة من الرفع، ولقطات الشاشة في `review-proofs/` محلية فقط.

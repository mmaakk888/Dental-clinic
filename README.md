# نظام إدارة عيادة الأسنان

المصدر الأصلي بواجهة عربية للموبايل والكمبيوتر. آخر توجيه للمالك هو تطوير النسخة المحلية وحفظ المصدر في GitHub، دون ربطه بشركة استضافة أو نشر تلقائي.

## تشغيل التصميم المحلي الأصلي

ثبّت Node.js وفق `package.json` وإصدار pnpm المحدد فيه، ثم نفّذ من مجلد المشروع، كل سطر على حدة:

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm preview:local
```

افتح **http://127.0.0.1:4173/** بدون `?clinic-cloud=1` وبدون `?firebase-setup=1`. المسار الأول هو `App.tsx` الأصلي؛ العلامتان تفتحان مسارين مختلفين لتشغيل/تجهيز Firebase وليستا شرطًا للنسخة المحلية.

لو كان المنفذ4173 مستخدمًا فلا توقف عملية مجهولة ولا تختَر منفذًا مختلفًا لاسترجاع البيانات: تحقق أولًا من المعاينة القائمة. أُضيف `--strictPort` حتى لا ينقلك الخادم بصمت إلى عنوان آخر. بيانات المتصفح مرتبطة بالعنوان والمنفذ وملف المتصفح؛ `localhost` و`127.0.0.1` ليسا نفس مساحة التخزين.

للتطوير مع تحديث المصدر المباشر والخادم المحلي الاختياري:

```bash
pnpm dev
```

استخدم الرابط الذي يظهر في الطرفية. احتفظ بنسخة احتياطية قبل نقل بياناتك بين المنافذ؛ هذا الأمر لا ينقلها تلقائيًا. معاينة `preview:local` تقرأ آخر `dist`، لذلك أعد `pnpm build` بعد تعديل المصدر ثم حدّث الصفحة. وظائف الذكاء الاصطناعي/مزود واتساب ليست مفعلة تلقائيًا.

## الفحص

```bash
pnpm exec tsc --noEmit
pnpm test
pnpm build
```

الاختبارات تستخدم سجلات مصطنعة؛ لا تحفظ بيانات مرضى أو كلمات سر كملفات اختبار أو داخل GitHub. مسارات `dist` و`build` و`.firebase` وملفات البيئة وصور المراجعة لا تدخل المصدر.

## البيانات والأمان والنشر

- النسخة المحلية تحفظ التشغيل في المتصفح. صلاحيات السكرتيرة وساعات العمل فيها ضوابط للواجهة المحلية، وليست حماية خادم ضد مالك الجهاز أو من يعدّل المتصفح. استخدم التصدير/النسخ الاحتياطي المصرح به واحفظ النسخ في مكان خاص خارج المستودع.
- المصدر يحتوي أيضًا على تشغيل Firebase منفصل، بحساب المالك فقط حاليًا. لا تعتبره نفس مسار المحلي، ولا تنشره تلقائيًا لمجرد تحديث GitHub.
- لم يُنجز بعد خادم PHP/MySQL مستقل. **رفع `dist` إلى cPanel قد يعرض ملفات الواجهة، لكنه لا ينشئ حسابات أو قاعدة بيانات مشتركة أو يحوّل التخزين المحلي إلى خادم.** لا تفتح بوابة المحلي للمضيف العام كاختصار.
- cPanel لوحة إدارة وليست اسم شركة أو ضمانًا لدعم Node.js. أي نسخة PHP/MySQL مستقبلية تحتاج ربطًا واختبارات منفصلة؛ لا تتطلب تغيير التصميم الأصلي.
- تحديث الكود لا يتضمن نقل أو حذف بيانات المتصفح أو Firestore، ولا نشر قواعد أو استضافة أو تفعيل فوترة.

التفاصيل التشغيلية والنسخ المحلي في [دليل المالك](CLINIC-OWNER-GUIDE.ar.md). الحالة الفعلية والقيود والتاريخ في [قائمة المراجعة](RELEASE-CHECKLIST.ar.md).

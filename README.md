# نظام إدارة عيادة الأسنان

النسخة المعتمدة الحالية: **PHP/MySQL v12** بنفس التصميم العربي المعتمد، بعد استكمال الفحص البصري وتصحيح محاذاة النص العربي في الدخول، مع الحفاظ على الروشتة والجلسات والدفعات والواتساب المراجَعين. لا تغيير في مخطط SQL أو بيانات التشغيل.

بعد تنزيل المستودع ادخل `app` ثم نفّذ أوامر pnpm الواردة في دليله. `pnpm build` ينتج حزمة كاملة للتثبيت الجديد وملفات النشر المنفصلة من نفس المصدر الحالي. ارفع محتويات htdocs فقط؛ لا ترفع المستودع أو الأرشيف أو SQL أو الإعدادات الخاصة أو مفاتيح التوقيع أو بيانات المرضى إلى مجلد الدومين أو GitHub.

ملفات الاستكمال تحفظ سياق العمل مع الكود، لا تنقل المحادثة حرفيًا أو قاعدة البيانات أو الأسرار بين الحسابات. حدّث سجل المشروع والتسليم بعد كل دورة عمل مهمة؛ لا تعِد تأسيس المشروع عند تغيير الحساب.

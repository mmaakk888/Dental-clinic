# نظام إدارة عيادة الأسنان — PHP/MySQL

واجهة عربية React/Vite بنفس التصميم المعتمد، بقاعدة MySQL وجلسات وصلاحيات PHP من السيرفر. تعمل على استضافة PHP مشتركة، دون Node.js أو اعتماد Firebase.

## البداية

ابدأ من [دليل التثبيت](portable/INSTALL.ar.md). تستورد مخطط الجداول فقط، وتضبط الاتصال خارج htdocs، ثم تنشئ حساب المدير بنفسك من المُثبّت. يبدأ المرضى والمواعيد وجهات الاتصال والمعامل والمصروفات والخامات وفهارس الخدمات والأدوية فارغة. لا حساب/كلمة سر افتراضية ولا نقل بيانات قديمة.

## التطوير والبناء

```powershell
pnpm install --frozen-lockfile
pnpm lint
pnpm test
pnpm build
```

النتيجة في build/portable-artifacts: حزمة htdocs، وحزمة SQL/إعدادات خاصة/أداة استرجاع كلمة السر، والمصدر الحالي. لا ترفع المصدر أو SQL إلى مجلد الدومين. الإصدار السابق لا يُستبدل بصمت.

المعاينة: PHP CLI 8.2+ مع pdo_mysql وقاعدة محلية منفصلة وملف اتصال خاص. اضبط CLINIC_LOCAL_CONFIG وCLINIC_PHP_BINARY عند الحاجة، ثم pnpm dev على5173، أو pnpm preview على4174 بعد البناء. لا تُنشأ بيانات تلقائيًا. التفاصيل بالدليل.

## التحقق والأمان

راجع [نتائج الاختبار](portable/VERIFICATION.ar.md) و[المراجعة البصرية والأداء](portable/DESIGN-REVIEW.ar.md). الصلاحيات والحسابات المالية تُفرض في PHP؛ لا يُعد إخفاء زر حمايةً للبيانات. النسخ الاحتياطية المستقبلية من النظام وSQL تبقى خاصة. لا اتصال بالمشروع السحابي القديم أو تعديل بياناته.

- [تحديث نسخة موجودة مع الحفاظ على البيانات](app/portable/UPDATE.ar.md)

بعد تنزيل المستودع ادخل `app` ثم نفّذ أوامر pnpm الواردة في دليله. `pnpm build` ينتج حزمة كاملة للتثبيت الجديد وملفات النشر المنفصلة من نفس المصدر الحالي. ارفع محتويات htdocs فقط؛ لا ترفع المستودع أو الأرشيف أو SQL أو الإعدادات الخاصة أو مفاتيح التوقيع أو بيانات المرضى إلى مجلد الدومين أو GitHub.

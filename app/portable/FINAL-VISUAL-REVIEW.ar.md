## اختبار صورة الروشتة

جُهزت صفحة اختبار للمكوّن فقط، بلا ملف مريض أو اتصال بسجلات سريرية، وبنصوص صريحة أنها ليست وصفة علاجية. استُخدم `createPrescriptionDocument` و`renderPrescriptionImage` الفعليان، لا رسم بديل.

نجح توليد PNG بمقاس1118×1588 من ورقة559×794، بحجم84,912بايت في هذه العينة. قورنت الورقة والصورة جنبًا إلى جنب: مواضع الشعار الافتراضي والإطار والحقول والنص المختلط والتذييل محفوظة، دون انعكاس. اختلاف تنعيم حروف المتصفح والصورة ليس ضمان تطابق بكسلي. لا يُعد ذلك اختبار إرسال واتساب أو طابعة أو كل شعار مرفوع فعليًا؛ جلب الشعار المحمي والتفويض والحدود تغطيها الاختبارات الآلية أيضًا.

صفحة المكوّن وملفاتها وشواهد الجولة موجودة في مجلدات خاصة محلية فقط، ولا تدخل ملفات الموقع أو المصدر المرفوع. صور الجولة محفوظة تحت `review-proofs/final-v11-20261021`؛ بدأت بمراجعةv11 ثم أُعيد فحص الدخول بعد تصحيحv12. حزمة صور الفحص مستقلة عن حزمة نشر الموقع.

## الفحص البرمجي والمالي

- 893 اختبار JS/TS ناجحًا، صفر فشل أو تخطٍّ، ومنها فحص جديد يمنع رجوع محاذاة النص العربي الفارغ.
- 193 فحص HTTP/SQL و62 فحص تحديث واستعادة/رجوع على قواعد loopback مصطنعة منفصلة.
- TypeScript وصياغة23 ملف PHP ناجحة. لا ترحيل SQL جديد أو تعديل أرصدة قائمة.
- اختبارات API تشمل رحلة المريض والزيارة بلا ملف والجلسات والتحصيلات الجزئية والتركيبات وأسعار المعامل والسداد والموردين والصلاحيات والنسخ إلى قاعدة أخرى. هذا غير ادعاء اختبار يدوي لكل هذه الحالات في المتصفح.
- لم يظهر خطأ JavaScript غير متوقع في سجل المتصفح المفحوص؛ ظهر تحذير متوقع لأن موصل الذكاء الاصطناعي غير مفعّل، وظهرت اقتراحات الحجز المحلية بوضوح بدل نتيجة آلية وهمية.

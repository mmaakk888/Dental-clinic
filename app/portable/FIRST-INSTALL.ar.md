# ابدأ من هنا — النسخة الكاملة للتثبيت لأول مرة

هذه الحزمة تحتوي أحدث نسخة كاملة من الموقع، وليست ملف تحديث تراكمي. لا تحتاج تثبيت إصدار أقدم قبلها. الإصدار الفعلي مكتوب في `installation-manifest.json` وفي `htdocs/release.json`، والبصمات في `SHA256SUMS.txt`.

## محتويات الحزمة

- `htdocs/`: ملفات الموقع الجاهزة، بما فيها الواجهة والتصميم وPHP والمثبت. ارفع **محتويات هذا المجلد فقط** إلى جذر الدومين (`htdocs` أو `public_html`)، مع الملفات المخفية مثل `.htaccess`.
- `private/`: مخطط قاعدة البيانات، وقالب الاتصال، والإعدادات الأولية، والأدلة والأدوات الخاصة. **لا ترفعه كاملًا داخل الدومين.**
- `source/clinic-source.zip`: المصدر الحالي للتطوير والرجوع إليه. لا ترفعه إلى مجلد الموقع العام.

لا توجد قاعدة مرضى منسوخة أو كلمات سر أو بيانات المعاينة. تنشئ قاعدة جديدة وحساب مدير بنفسك؛ المرضى والخدمات والأدوية والمعامل والمواعيد والمعاملات تبدأ فارغة. قيمة الكشف الأولية 100 جنيه قابلة للتغيير ولا تُحصّل تلقائيًا.

## التثبيت باختصار

1. اختر استضافة Apache/PHP 8.2+ وMySQL، وفعّل HTTPS للدومين. لا تحتاج Node.js على الاستضافة. راجع المتطلبات الإضافية للنسخ الاحتياطي والتحديث في الدليل الكامل.
2. أنشئ قاعدة MySQL فارغة ومستخدمًا خاصًا بها من لوحة الاستضافة، ثم استورد `private/schema.sql` عبر phpMyAdmin.
3. ارفع محتويات `htdocs/` إلى جذر الدومين. لا ترفع حزمة التسليم كاملة ولا مجلدَي `private` و`source` داخله.
4. خارج جذر الدومين، أنشئ `clinic-private` بجانب `htdocs` أو `public_html`. انسخ محتويات `private/clinic-private` إليه، وغيّر اسم `config.example.php` إلى `config.php`.
5. اضبط رابط HTTPS وبيانات MySQL داخل `config.php`، وأنشئ `app_key` و`install_token` عشوائيين منفصلين، كل منهما 64 خانة hexadecimal. لا تستخدم بيانات الاتصال المحلية ولا كلمة سر حسابك بدل المفتاح. طريقة التوليد والبديل عند منع الملفات خارج الجذر في `private/INSTALL.ar.md`.
6. افتح `https://YOUR-DOMAIN/install.html`، واكتب رمز التثبيت ثم أنشئ حساب المدير بكلمة سر تختارها. لا توجد كلمة سر افتراضية. يُقفل المثبت بعد النجاح؛ أزل قيمة `install_token` من الملف الخاص.
7. سجّل الدخول واضبط اسم العيادة والخدمات والأسعار والمعامل. اختبر الحفظ وRefresh والصلاحيات ورفع صورة اختبار قبل إدخال بيانات حقيقية، ثم اضبط النسخ الاحتياطي حسب إمكانات الاستضافة.

التفاصيل: `private/INSTALL.ar.md`. نتائج وحدود الفحص: `private/VERIFICATION.ar.md`. النسخ والنقل: `private/BACKUP.ar.md`. التحديثات اللاحقة: `private/UPDATE.ar.md`.

**تنبيه:** هذه للتثبيت الجديد فقط. إذا أصبحت لديك بيانات على استضافة لاحقًا، لا تعِد استيراد `schema.sql` أو إنشاء المدير لتحديث التصميم؛ استعمل صفحة «تحديث النظام» وحزمة تحديث موقعة متوافقة، مع نسخة احتياطية أولًا. إعدادات البريد والجدولة والواتساب الآلي ليست مفعلة دون ضبط واختبار حقيقيين.

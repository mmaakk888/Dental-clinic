## على جهاز آخر أو من GitHub

1. افتح [المستودع الخاص](https://github.com/mmaakk888/Dental-clinic) بحساب GitHub لديه صلاحية الوصول. إن استخدمت موصل GitHub في الحساب الجديد، امنحه الوصول لهذا المستودع تحديدًا؛ لا ترسل كلمة سر GitHub أو Codex في الشات.
2. استخدم فرع `main`. التطبيق الحالي داخل `app/`؛ `archive/` ليس نسخة للتشغيل. يمكن تنزيل المصدر أو استنساخه ثم فتح `app` محليًا. إتاحة موصل للكود وحدها لا تنشئ خادم PHP/MySQL محليًا.
3. اقرأ ملفات الحفظ قبل طلب التعديل، وجهّز بيئة PHP/MySQL منفصلة حسب [دليل التثبيت](portable/INSTALL.ar.md). Node22+ وpnpm للبناء على جهاز التطوير فقط، ولا يلزمان على الاستضافة.
4. لا تأتي قاعدة اللاب أو المرفقات أو ملف الاتصال أو كلمات السر من GitHub. عند الحاجة إليها استخدم نسخة النظام المشفرة ومفتاحها المنفصل، أو انقل الإعدادات الخاصة بأمان خارج الشات والمستودع. التثبيت الجديد المطلوب الآن فارغ، لذلك لا يحتاج بيانات قديمة.
5. مفتاح توقيع التحديثات الخاص منفصل أيضًا؛ لا تنشئ مفتاحًا بديلًا عشوائيًا إذا وُجدت نسخ مثبّتة تثق بالمفتاح الحالي.
